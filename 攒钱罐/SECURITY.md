# 攒钱罐 · 安全与隐私说明（SECURITY）

> 本文件说明攒钱罐在"隐私最小化 / 法律合规 / 防信息泄露"上的设计与边界。
> 适用于微信小程序版（`攒钱罐/`）及其订阅消息云函数。网页版（`攒钱罐-web/`）纯本地存储，不联网。

---

## 0. 一句话结论

**本应用不接入微信支付、不读取任何交易流水、不采集银行卡/凭证/真实姓名/手机号。**
云端（如开启）只保存两样东西：你的微信 `openid` 和"今日聚合预算数字"（remaining / strictRemaining）。
推送的订阅消息也**只有聚合数字**，没有任何单笔消费、商户或备注。

---

## 1. 数据清单

### 1.1 始终保存在本机（不上云）
| 数据 | 说明 | 是否出本机 |
|------|------|-----------|
| 账单明细（金额/分类/备注/时间） | 用户手动输入 | 否 |
| 存钱目标、愿望清单 | 用户手动输入 | 否 |
| 罚金记录、存钱罐余额 | 计算得出 | 否 |
| 设置项（罚金比例/限额/开关） | 用户设置 | 否 |

> 以上全部存于 `wx.setStorageSync`（小程序）/ `localStorage`（网页），**没有任何网络请求会携带它们**。

### 1.2 仅在"已开启云开发 + 用户授权"时上云（最小化）
| 集合 | 字段 | 说明 |
|------|------|------|
| `reminder_profile` | `_openid`, `pushHour`, `enabled`, `tz` | 仅提醒偏好 |
| `daily_snapshot` | `_openid`, `date`, `remaining`, `strictRemaining` | 仅当日聚合剩余额度 |

**不含**：交易明细、商户名、备注、姓名、手机号、地址、设备号、位置、相册等任何 PII。

---

## 2. 法律与合规边界（诚实说明）

- **不触碰的红线**：不接入支付通道、不爬取/读取微信支付账单、不索要身份与金融凭证——这些本应用**根本没有代码路径**。
- **《个人信息保护法》（PIPL）对齐**：
  - **最小必要**：云端只存 openid + 聚合数字。
  - **告知—同意**：订阅消息必须用户点击 `wx.requestSubscribeMessage` 明确授权才发送；未授权绝不会推送。
  - **删除权**：提供「清除云端数据」（`clearCloud` 云函数）彻底删除本人云端数据。
  - **撤回同意**：关闭开关即停止推送（`setReminder` 停用）。
- **我能保证的**：代码层面做到最小化采集、字段白名单、服务端校验、日志脱敏、可删除。
- **我无法保证的（诚实告知）**：
  - 微信平台自身的合规性与安全不在本代码控制范围；
  - 用户本人设备/账号被盗、或自行导出数据外泄，不在本应用责任范围。
  - 因此额外提供**"完全本地模式"**：不填 `CLOUD_ENV` 时，所有云端能力自动关闭，数据零外传。

## 3. 防火墙（纵深防御）实现位置

| 层 | 文件 | 防护 |
|----|------|------|
| 客户端校验 | `utils/security.js` | 字段白名单、数值钳制、文本清洗、openid 脱敏 |
| 变更钩子 | `utils/store.js` → `save()` | 只触发聚合快照推送，不传明细 |
| 云初始化 | `app.js` | `traceUser:false`，未配置环境则完全不联网 |
| 云端校验 | 各 `cloudfunctions/*/index.js` | 拒绝未知字段、忽略客户端 openid、仅存白名单字段 |
| 日志 | 各云函数 | openid 只打印前 4 位 + `****` |
| 删除权 | `cloudfunctions/clearCloud` | 按本人 openid 删除全部云端数据 |

**关键不变量**：`openid` 一律由云端 `cloud.getWXContext().OPENID` 取得，客户端传入的 openid 字段被防火墙直接丢弃。

---

## 4. 部署安全建议

1. 云开发数据库集合 `reminder_profile` / `daily_snapshot` 的安全规则设为"仅创建者可读写"（默认即如此）。
2. `utils/config.js` 的 `SUBSCRIBE_TEMPLATE_ID` / `CLOUD_ENV` 必须替换为你自己的，切勿提交真实密钥到公开仓库。
3. 订阅消息模板字段仅使用固定文案 + 聚合金额，不要在模板里加"备注/明细"类字段。
4. 定期用「清除云端数据」或卸载重装来抹除本地数据。

---

## 5. 仍想更保守？

- 不填 `CLOUD_ENV` → 纯本地，无任何网络请求。
- 不点「每日预算提醒」开关 → 不授权订阅消息，永不推送。
- 不调用任何云函数 → 云端零数据。
