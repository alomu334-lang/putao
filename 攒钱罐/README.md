# 攒钱罐 · 微信小程序

一个帮你**管住每日钱包**的存钱小程序。核心机制：每天设置"可用金额"，花一笔就实时提醒"今日还可使用多少"；一旦想花的钱超过今日剩余，支付被**自动拦截**，并缴纳罚金进入存钱罐——用"痛感"逼自己自律。

## 一、你的三大核心需求（已实现）

| 需求 | 实现位置 | 说明 |
|------|----------|------|
| 每天都可以添加可使用金额 | `pages/budget` + 首页"加额度" | 每天重新设置今日可用金额；支持快速加 50/100/200…，可选"昨日结余自动结转" |
| 用了一笔钱后提醒今日只可再使用金额 | `pages/expense` + 首页大字号"今日还可使用" | 每记一笔，首页与记账页实时刷新剩余额度，并配进度条预警（≥70% 橙、≥90% 红） |
| 超出则无法支付，做成惩罚 | `pages/expense` 拦截弹窗 | 超支时支付被拦截，弹出惩罚弹窗：认罚缴纳罚金（默认超出部分的 20%，最低 ¥1）进存钱罐；也可"只花光今日剩余"或返回改金额 |

## 二、市面存钱 App / 小程序常见功能（已集成）

- **今日额度 + 进度预警**：可视化今日花销占比，临近上限变色提醒。
- **账单明细**（`pages/records`）：按日期分组，支持 全部/支出/收入 筛选，长按删除。
- **存钱目标**（`pages/goal`）：内置 **52 周存钱法**、**365 天存钱法**、**自定义目标**三种模板，可勾选分期、随时"存一笔"、看完成度。
- **统计**（`pages/stats`）：本月支出、分类占比、近 7 天趋势柱状图、累计罚金、累计总支出。
- **自律打卡**（`pages/index`）：连续打卡天数，激励每天坚持。
- **罚金记录**（`pages/penalty`）：每次超支的罚金与超支金额明细，全部自动进入存钱罐。
- **设置**（`pages/mine`）：罚金比例（10%/20%/30%/50%）、昨日结余结转开关、结余自动存钱开关。
- **数据导出**：一键把全部账单复制到剪贴板（CSV 格式），方便备份到微信/备忘录。
- **本地存储**：所有数据存在手机本地（`wx.setStorageSync`），不上云，隐私安全。

## 三、如何在微信开发者工具里运行

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 打开工具 → 选择「小程序」→「导入项目」。
3. 项目目录选择本文件夹（`攒钱罐/`）。
4. AppID：
   - 没有账号可先选「测试号」直接预览；
   - 要真机调试 / 发布，需注册小程序账号并在 `project.config.json` 把 `"appid"` 改成你自己的 AppID。
5. 点击「编译」，即可在模拟器里体验全部功能。

## 四、如何发布上线（让微信好友能用）

1. 在 [微信公众平台](https://mp.weixin.qq.com/) 注册小程序，拿到 AppID。
2. 开发者工具里「上传」代码，填写版本号与备注。
3. 登录公众平台 →「管理 → 版本管理」提交审核。
4. 审核通过后「发布」，即可在微信里搜索/扫码使用。

## 五、代码结构

```
攒钱罐/
├─ app.js / app.json / app.wxss      # 全局配置与样式（绿色主题）
├─ project.config.json / sitemap.json
├─ utils/
│  ├─ store.js     # 全部业务逻辑与本地存储（额度/账单/目标/罚金/打卡）
│  ├─ util.js      # 日期、金额、52周/365天计划等工具
│  └─ money.wxs    # WXML 金额格式化（¥1,234.50）
└─ pages/
   ├─ index     # 今日（额度/剩余/打卡/今日明细）
   ├─ budget    # 设置每日可用金额
   ├─ expense   # 记一笔（含超支拦截+罚金惩罚）
   ├─ records   # 账单明细
   ├─ goal      # 存钱目标（52周/365天/自定义）
   ├─ stats     # 统计
   ├─ penalty   # 罚金记录
   └─ mine      # 我的（设置/导出/清空）
```
