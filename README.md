> **📌 简历简介**：从 0 到 1 设计并实现了一款隐私优先的每日预算 / 存钱应用，一套业务逻辑同时驱动微信小程序与网页版；实现超支拦截、重点类目管控与愿望解锁等完整交互，并以字段白名单、日志脱敏构建隐私防火墙，配套 Puppeteer 截图与 jsdom 端到端测试。

## 这个项目能展示什么（给面试官看）

- **双端同构架构** —— 一套业务逻辑 `store.js` 同时驱动微信小程序与网页版，UI 分别用 WXML / HTML 实现，体现抽象与复用能力。
- **扎实的前端工程能力** —— 原生 HTML / CSS / ES6 单页应用 + 微信小程序，不靠框架堆砌，代码可读、可测、可控。
- **隐私优先的安全设计** —— 不接支付、字段白名单、服务端校验、日志脱敏、一键清除，体现合规与安全意识。
- **自动化验证** —— Puppeteer 截图 + jsdom 端到端测试，体现工程质量而非"跑不起来"。
- **细节体验** —— 支付拦截、罚金惩罚、每日省钱鼓励、愿望解锁撒花动画。

## 技术栈

- **前端**：原生 HTML5 / CSS3 / ES6（单页应用，无框架依赖）
- **状态管理**：自研 `store.js`，localStorage 持久化
- **微信小程序**：WXML / WXSS / JS + 微信云开发（订阅消息云函数模板）
- **安全**：自研 `security.js`（字段白名单 / 数值钳制 / 文本清洗 / openid 脱敏）
- **测试 / 验证**：Puppeteer 自动化截图 + jsdom 端到端测试

## 核心功能

- 每日可用金额设定与实时余额提醒
- 超支自动拦截 + 按罚金比例扣入存钱罐
- **奶茶 / 炸鸡 / 游戏重点类目独立限额与拦截**
- 每日省钱鼓励与存钱罐累计
- 52 周 / 365 天 / 自定义存钱目标
- 愿望清单：存够自动解锁 + 撒花动画
- 分类统计、近 7 天趋势、罚金记录
- 数据导出 / 导入 JSON 备份

## 安全与隐私

- **不接入微信支付**，不读取交易流水
- 云端只存聚合数字（剩余额度），不存任何单笔消费 / 商户 / 备注
- 字段白名单、数值钳制、文本清洗、openid 脱敏
- 支持一键清除云端数据、完全本地模式

完整安全说明：[SECURITY.md](./攒钱罐/SECURITY.md)

## 微信小程序版

同构的小程序代码在 [`攒钱罐/`](./攒钱罐)，已实现完整界面与交互、订阅消息云函数模板、隐私防火墙。接入微信云开发后可启用多设备同步与每日剩余额度定时推送。

## 快速开始

```bash
# 网页版：直接双击 攒钱罐-web/index.html，或起本地服务
cd 攒钱罐-web && python3 -m http.server 8080
# 小程序版：用微信开发者工具导入 攒钱罐/ 目录
```
