# 云函数部署说明（订阅消息 / 预算提醒）

本目录包含 4 个微信云开发函数，用于实现"每日预算提醒"订阅消息。
**全部函数只处理聚合预算数字，不接收任何交易明细。**

## 函数清单
| 函数 | 触发方式 | 作用 |
|------|----------|------|
| `setReminder` | 客户端调用 | 开启/关闭提醒、或 `wipe:true` 删除本人配置 |
| `syncSnapshot` | 客户端调用（每次记账后自动） | 写入今日聚合剩余额度 |
| `subscribeReminder` | 定时器（每小时） | 向当前小时应推送的用户发订阅消息 |
| `clearCloud` | 客户端调用 | 彻底删除本人云端数据（删除权） |

## 部署步骤
1. 微信开发者工具 → 开通「云开发」，记下**环境 ID**。
2. 编辑 `../utils/config.js`：
   - `CLOUD_ENV` 填你的环境 ID
   - `SUBSCRIBE_TEMPLATE_ID` 填你在 **mp.weixin.qq.com → 订阅消息** 申请的"预算提醒"模板 ID
3. 在 mp 后台申请订阅消息模板，字段建议（以你实际申请为准）：
   - `thing1` 提醒事项 → 固定文案「今日预算提醒」
   - `amount2` 剩余可用 → `¥xx.xx`
   - `date3` 日期 → `YYYY-MM-DD`
   若模板字段 key 不同，请同步修改 `subscribeReminder/index.js` 的 `data`。
4. 分别右键每个函数目录 →「上传并部署：云端安装依赖」（或 `wx-server-sdk` 已在云端环境预置）。
5. 数据库新建集合 `reminder_profile`、`daily_snapshot`，安全规则保持默认（仅创建者可读写）。
6. `subscribeReminder` 已带 `config.json` 定时器（`0 0 * * * * *`，每小时整点触发）；上传后到云函数「触发器」确认已生效。
7. 在小程序「我的 → 提醒与云 → 每日预算提醒」打开开关，按提示授权即可。

## 安全要点（务必遵守）
- 模板字段**不要**包含备注/商户/明细类内容，只放聚合金额与日期。
- `config.js` 中的环境 ID / 模板 ID 属于配置，勿公开到仓库。
- 函数已内置：拒绝未知字段、忽略客户端 openid、日志脱敏、可删除。不要移除这些防护。
